About Me

อ่านได้นะครับประวัติไม่ได้บูด อิอิ

สวัสดีครับ ผมชื่อธรรมนูญ ศรีจันทร์ ชื่อเล่น ก้ำ หรือ กั้ม แล้วแต่จะเรียกเลยไม่ต่างกันหรอก ผมเริ่มต้นการเรียนจากมัธยมต้นจากโรงเรียนนารีรัตน์จังหวัดแพร่เมื่อปี พ.ศ.2563 (ม.1) จนจบการศึกษาในปี พ.ศ.2566 (ม.3) และได้ศึกษาต่อในระดับ (ปวช.) ปี พ.ศ.2566 จนจบ (ปวช.) ปี พ.ศ.2568
ปัจจุบันกำลังศึกษาต่ออยู่ในระดับ (ปวส.) ปี พ.ศ.2569

ปัจจุบันเข้ามาศึกษาต่อในระดับ (ปวช.) ปี พ.ศ.2566 ช่วงปีที่ 1 ได้เรียนและฝึกทักษะการฝึกเขียนโค้ด ในช่วงนั้นได้เรียนเขียนโค้ดภาษา HTML และ CSS ในการออกแบบโครงสร้างเว็บและตกแต่ง และรวมถึงได้เรียนภาษา C ในช่วงเทอมที่ 1 และเทอมที่ 2
ขึ้นปีที่ 2 ได้เรียนการใช้บอร์ด Arduino ในการต่อวงจรและได้เขียนโค้ดสั่งการควบคู่ไปด้วย และได้สร้างแอพ UX ให้ทำงานสั่งการผ่านเว็บไซต์ส่วนตัวได้ และได้ออกแบบแอพพลิเคชันให้สร้างผ่านแอพสำเร็จรูปจาก (Play Store / App Store) จะเป็นการออกแบบ UX/UI ขนาดย่อมให้จำลองสำหรับผู้ใช้ที่จะมาใช้งานแอพของเรา และได้เรียนภาษา C# (C-Sharp), C++ และ PHP ออกแบบฐานข้อมูลไปด้วยกัน
ช่วงเทอมที่ 2 ได้ออกฝึกงานที่ร้าน หจก.เวิร์ลไวด์คอมพิวเตอร์แพร่ ใช้เวลาฝึกอยู่ที่ร้าน 4 เดือน ได้เรียนรู้การซ่อมคอมพิวเตอร์และการประกอบคอมพิวเตอร์ การลง Windows และโปรแกรมต่างๆ และได้เรียนรู้การทำงานของระบบคอมพิวเตอร์และอุปกรณ์ต่อพ่วงต่างๆ
ขึ้นปีที่ 3 ได้เริ่มเรียนไฟฟ้าและอุปกรณ์ IoT มากขึ้นในการเอาไปทำโปรเจกต์จบของ (ปวช.3) ได้ศึกษาโค้ดพร้อมกับอุปกรณ์ที่จะเอามาทำโปรเจกต์ไปด้วยตลอดภาคเรียนที่ 1 พร้อมทั้งการเสนอชื่อโปรเจกต์ที่จะทำโดยแต่ละกลุ่มจะมีกันอยู่ 3 คน และทำเอกสารโปรเจกต์ควบคู่ไปด้วย โปรเจกต์ที่ได้ทำคือราวตากผ้า (อัจฉริยะ) เทอมแรกได้ต่อวงจรบ่อยมากและได้ทำมินิโปรเจกต์ส่งเป็นครั้งแรกถือว่าผ่านใช้ได้ รวมถึงนำเสนอโปรเจกต์จบ 50%
ช่วงปิดเทอมและเปิดเทอมที่ 2 ได้ออกแบบและทำโปรเจกต์ระหว่างรอเปิดเรียนยาวๆ ทั้งลองผิดลองถูกติดลูปวนไปจนเปิดเทอม และก็ได้ต่อเติมตกแต่งจนถึงท้ายเทอมพร้อมทั้งทำเอกสารโปรเจกต์จบ 100% ไปด้วย

ขึ้น ปวส.1 (ปัจจุบัน) ได้เรียนภาษาเพิ่มคือ Python และกลับมาวนเรียนภาษา C อีกครั้ง แต่ภาษา Python เรียนแล้วสนุกมาก ได้ลองออกแบบอะไรที่ไม่เคยออกแบบมาก่อน ชอบมากๆ และได้ทำมินิโปรเจกต์อีกครั้ง และกลับมาเรียน IoT ที่ผสมผสาน Network
